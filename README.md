### Cloning this repository

1. Log into Fir
2. If it's your first time:
    - `cd ~/scratch`
    - `git clone https://github.com/INN-SFU/BRS-Training.git`
3. If you've cloned the repository before:
    - `cd ~/scratch/BRS-Training`
    - `git pull`
